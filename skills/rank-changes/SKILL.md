name: rank-changes
description: Compare compatible saved Google rank snapshots or supplied rank reports and explain movement without treating missing coverage as a zero rank.
---
Read ../../references/research-rules.md.

Find the selected before/after snapshots in supplied material or seo_usage. Compare domain, keyword, country/language, search depth and dates. When settings differ, explain the mismatch and request a compatible pair rather than implying a measured change.

Use seo_rank_comparison with the two returned owned IDs when connected. Positive positions_gained means improvement. A domain absent from bounded results is not rank zero; do not subtract an invented position. Distinguish a single snapshot change from a trend and avoid assigning a cause without supporting evidence.

Return the observed change, coverage limitations and a sensible next check. Do not start fresh ranking requests or enroll the user in weekly checks merely because a compatible pair is missing.
